📊 E-Commerce Sales Analysis Dashboard
📌 Project Overview

This project is an E-Commerce Sales Analysis Dashboard created using Microsoft Power BI.

The purpose of this project is to transform raw E-Commerce sales data into meaningful insights through data cleaning, analysis, visualization, and interactive reporting.

The project uses two CSV datasets — Orders and Details — which were analyzed and connected in Power BI to create an interactive sales dashboard.

📂 Dataset

The repository contains two datasets:

Orders.csv

Contains order-level information, including details such as:

Order ID
Order Date
Customer details
Location
Region
State
City
Details.csv

Contains product and transaction-level information, including:

Order ID
Product
Category
Sub-Category
Quantity
Sales
Profit
Other transaction details
📊 Dashboard Features

The dashboard provides insights into:

💰 Total Sales
📈 Total Profit
📦 Total Quantity Sold
🛒 Order Performance
🏷️ Sales by Category
📋 Sales by Sub-Category
💹 Profit Analysis
🌍 Regional & State-wise Sales
📅 Sales Trends Over Time
🏆 Top-performing Products

Interactive filters allow users to explore the data based on different categories, regions, products, and time periods.

🎯 Objectives

The main objectives of this project are to:

Analyze overall e-commerce sales performance.
Identify top-performing products and categories.
Analyze sales and profit across different regions.
Understand sales trends over time.
Identify profitable and underperforming segments.
Present complex sales data through an easy-to-understand interactive dashboard.
💡 Key Business Questions

This dashboard can help answer questions such as:

Which products generate the highest sales?
Which categories are the most profitable?
Which regions contribute the most to overall sales?
How do sales change over time?
Which products have high sales but low profit?
Which categories or regions have opportunities for improvement?
